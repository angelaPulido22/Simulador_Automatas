## Errores reales que deben documentarse

Para cada error real ocurrido durante el desarrollo, registrar:

1. Síntoma observable.
2. Prompt completo utilizado para investigar o corregirlo.
3. Causa identificada.
4. Corrección aplicada.
5. Cómo se verificó que la corrección funcionó (salida de prueba o captura).

No rellenar esta sección con errores hipotéticos. Si un error ocurrió durante una sesión previa, recuperar la conversación y anotar el detalle con fidelidad.
